Fast builds. Small binaries. Real Haskell.

AIHC is a self-hosting Haskell compiler. It targets native machine code, LLVM IR and WebAssembly.

Install

Get the compiler, three ways.

Download a release binary, install an RPM, or build from source. The binaries are compiled by AIHC itself and need nothing else.

All releases →

macOS

curl -L https://github.com/ai-haskell-compiler/aihc/releases/download/v0.2.0/aihc-0.2.0-apple-arm64.tar.gz | tar -xz
sudo install aihc-0.2.0-apple-arm64/aihc /usr/local/bin/aihc

Release binary for Apple silicon. The core libraries are embedded in the executable.

Linux

curl -L https://github.com/ai-haskell-compiler/aihc/releases/download/v0.2.0/aihc-0.2.0-linux-amd64.tar.gz | tar -xz
sudo install aihc-0.2.0-linux-amd64/aihc /usr/local/bin/aihc

Release binary for x86-64. The core libraries are embedded in the executable.

Fedora

sudo dnf copr enable petersen/aihc
sudo dnf install aihc

RPMs for Fedora and EPEL from the petersen/aihc Copr.

From source

git clone https://github.com/ai-haskell-compiler/aihc.git
cd aihc
nix develop
cabal build exe:aihc
cabal list-bin exe:aihc

Needs Nix with flakes enabled. The flake provides GHC, Cabal and Clang, and the last command prints the path of the executable.

Features

Built to run the Haskell people actually write.

Three goals, in priority order: compatible with GHC, faster where GHC is slow by design, and reusable piece by piece.

GHC-compatible

Not Haskell 2010 plus a few extras. AIHC accepts GHC's extensions and ships the GHC.* modules that Hackage packages expect. It builds aeson, text, containers and vector.

Parallel by default

Parsing, name resolution, type checking and code generation are scheduled over every core. The 54 modules of text build in 3.2 seconds, against 28.0 for GHC at -O0.

Whole-program optimization

GHC optimizes one module at a time. AIHC sees the whole program before it generates code, which is how its -Os binaries come out a tenth of the size.

Three backends

Native machine code for AMD64 and ARM64, LLVM IR, and wasm32. One middle end, one runtime and one garbage collector serve all three.

Self-hosting

AIHC compiles AIHC. The compiler it produces compiles itself again, and the two executables are identical, byte for byte.

Owns every stage

Its own preprocessor, parser, type checker, optimizer, object emitter and runtime. No stage shells out to a tool it cannot change, so no bottleneck is out of reach.

A real runtime

A generational, incremental garbage collector with bounded pauses. Green threads that run in parallel. Software transactional memory.

Reusable libraries

The compiler is a set of packages: aihc-cpp, aihc-parser, aihc-resolve, aihc-tc and more. Each is meant to be useful without the rest.

How it's made

Designed by a human. Cranked out by robots.

A person holds the architecture and reviews every change. AI agents write the code: ChatGPT, Claude Opus and Qwen-Coder all contribute. They also write the tests, the benchmarks, the design documents and the blog.

The first commit landed in March 2026. Seven months later the compiler built itself.

Under construction

AIHC builds many Hackage packages, but not all of them. The base library is about half complete, and some language extensions are still missing.

The status tables in the README regenerate on every merge, so the numbers there are always current.
